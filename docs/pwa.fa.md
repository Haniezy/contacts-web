# نصب به‌صورت اپ (PWA)

به درخواست صاحب پروژه (۱۴ مهر ۱۴۰۵) دفترچه را می‌توان مثل یک اپ روی گوشی یا کامپیوتر نصب کرد. هیچ پکیج جدیدی اضافه نشده است.

## اجزا

- **manifest** (`src/app/manifest.ts`، آدرس `/manifest.webmanifest`): نام «دفترچه تلفن» / «دفترچه»، `start_url` برابر `/contacts`، نمایش `standalone` (بدون نوار مرورگر)، `dir: rtl` و رنگ پس‌زمینه تم روشن. `layout.tsx` آیکون اپل، `appleWebApp` و `theme-color` جدا برای تم روشن و تاریک را اضافه می‌کند.
- **آیکون‌ها** (`public/icons`): `icon-192.png` و `icon-512.png` با گوشه گرد، `maskable-512.png` تمام‌قاب (کتاب در محدوده امن ۸۰٪ برای برش اندروید) و `apple-touch-icon.png` بدون شفافیت. همه با `node scripts/make-icons.mjs` از لوگوی کتاب ساخته می‌شوند.
- **service worker** (`public/sw.js`، فقط در build تولید ثبت می‌شود تا توسعه فایل کهنه نگیرد):
  - فایل‌های ساخته‌شده (`/_next/static`، آیکون‌ها): اول کش.
  - صفحه‌ها و API فهرست (`/api/contacts` و `/api/contacts/duplicates`): اول شبکه؛ بدون اینترنت آخرین نسخه ذخیره‌شده، و برای صفحه‌ای که هرگز باز نشده `public/offline.html`.
  - هیچ چیز دیگری ذخیره نمی‌شود: API ورود و حساب، لینک‌های عمومی `/s/`، ریدایرکت‌ها، خطاها و هر درخواستی جز GET.
  - `sw.js` با `Cache-Control: no-store` سرو می‌شود تا نسخه جدید فوراً برسد؛ نام کش‌ها نسخه دارد (`v1`) و کش‌های قدیمی هنگام فعال‌سازی پاک می‌شوند.
- **حریم خصوصی:** چون صفحه‌های ذخیره‌شده اطلاعات همین حساب‌اند، `forgetOfflineData` (`src/lib/offline.ts`) همه کش‌ها را هنگام خروج، خروج از همه دستگاه‌ها، حذف حساب و هر ورود تازه پاک می‌کند.
- **بدون اینترنت:** یادداشت «اتصال اینترنت نداری؛ آخرین اطلاعات ذخیره‌شده رو می‌بینی.» بالای صفحه نمایش داده می‌شود (`src/components/pwa.tsx`). تغییر داده‌ها بدون اینترنت ممکن نیست.

## نصب از منو

گزینه «نصب اپ دفترچه» در منو (کشوی موبایل و منوی حساب دسکتاپ) پنجره کوچکی باز می‌کند (`src/components/contacts/install-sheet.tsx`):

- اگر مرورگر پیشنهاد نصب داده باشد (رویداد `beforeinstallprompt` در کروم، Edge و Samsung Internet)، دکمه «نصب» بالای پنجره پنجره رسمی نصب مرورگر را باز می‌کند.
- همیشه راهنمای دستی همان دستگاه هم آمده است: آیفون (دکمه اشتراک سافاری ← Add to Home Screen)، اندروید (منوی ⋮ ← نصب اپ / افزودن به صفحه اصلی) و کامپیوتر (آیکون نصب کنار نوار آدرس یا منوی ⋮).
- وقتی دفترچه به‌صورت اپ نصب‌شده باز است، این گزینه نمایش داده نمی‌شود.

## تست

`tests/e2e/pwa.spec.ts` روی هر سه اندازه: manifest، آیکون‌ها و هدر بدون کش `sw.js`؛ راهنمای نصب درست برای اندروید، کامپیوتر و آیفون؛ باز شدن فهرست بدون اینترنت و صفحه آفلاین برای صفحه دیده‌نشده؛ و پاک شدن همه صفحه‌ها و پاسخ‌های ذخیره‌شده پس از خروج.
