# ثبت‌نام و اتصال Cloudinary

Cloudinary عکس‌های مخاطبین را نگه‌داری می‌کند. [حساب رایگان](https://console.cloudinary.com/users/register_free) برای ثبت‌نام کارت بانکی نمی‌خواهد و طبق [شرایط پلن](https://cloudinary.com/documentation/billing_and_plans)، ۲۵ credit ماهانهٔ مشترک برای فضای ذخیره، پردازش و پهنای‌باند دارد؛ این به معنی ۲۵ گیگابایت مستقل برای هر بخش نیست.

۱. وارد صفحهٔ ثبت‌نام شوید، حساب بسازید و ایمیل را در صورت درخواست تأیید کنید. برای این پروژه محصول Image & Video API / Programmable Media را انتخاب کنید.
۲. وارد Console شوید و بخش API Keys را باز کنید. Cloud Name، API Key و API Secret را پیدا کنید.
۳. فایل `.env` موجود پروژه را باز کنید و موارد زیر را اضافه کنید. فایل را جایگزین نکنید؛ تنظیمات Neon و Auth باید حفظ شوند:

```dotenv
CLOUDINARY_CLOUD_NAME=نام-محیط-شما
CLOUDINARY_API_KEY=کلید-شما
CLOUDINARY_API_SECRET=راز-شما
```

API Secret را در چت یا Git نفرستید و در فرانت قرار ندهید. ساخت bucket در AWS، واردکردن کارت و ایجاد unsigned upload preset لازم نیست. متغیرهای قبلی AWS دیگر توسط بخش عکس استفاده نمی‌شوند.

۴. بعد از ذخیرهٔ فایل:

```bash
docker compose up -d --build app
```

۵. یک عکس JPEG، PNG یا WebP زیر ۵ MiB را برای مخاطبی که متعلق به حساب واردشده است، به `POST /api/contacts/:id/photo` ارسال کنید. قرارداد کامل در [راهنمای API](contacts.fa.md) است. با موفقیت آپلود، API لینک موقت تصویر را برمی‌گرداند. عکس در Cloudinary از نوع authenticated است؛ URL عمومی معمولی نباید آن را نمایش دهد.

تا زمانی که حساب و کلیدها تنظیم نشده‌اند، اتصال و آپلود واقعی تأیید نشده‌اند. تست‌های خودکار پروژه بدون حساب Cloudinary اجرا می‌شوند. پلن رایگان محدودیت مصرف دارد؛ روش تحویل خصوصی فعلی نیز نسبت به تحویل CDN عادی، پهنای‌باند بیشتری مصرف می‌کند که در راهنمای API توضیح داده شده است.
